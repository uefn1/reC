このページの埋め込みコード

GitHub Pages公開後はこの3行だけ。自分のサイトに貼るだけです。

<!-- 1. CSS --> <link rel="stylesheet" href="https://uefn1.github.io/reC/mycaptcha.css"> <!-- 2. ウィジェットを置く場所 --> <div id="my-captcha"></div> <!-- 3. JS + 初期化 --> <script src="https://uefn1.github.io/reC/mycaptcha.js"></script> <script> myCaptcha.render('my-captcha', { callback: (token, info) => { // tokenをサーバーに送る // info.score で信頼度を確認 submitBtn.disabled = false; } }); </script>

ローカルで試す場合

<link rel="stylesheet" href="./mycaptcha.css"> <div id="my-captcha"></div> <script src="./mycaptcha.js"></script>

※ この demo.html はローカル版（./mycaptcha.js）で動いています。
